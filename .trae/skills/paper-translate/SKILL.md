# 论文翻译助手 (Paper Translate)

专门用于学术论文翻译的技能，确保专业术语准确、表达地道。

## 主要功能

### 1. 中译英
- 学术论文全文翻译
- 摘要翻译（符合国际期刊要求）
- 学位论文翻译
- 学术邮件翻译

### 2. 英译中
- 英文论文翻译
- 技术文档翻译
- 学术报告翻译

### 3. 术语管理
- 专业术语统一翻译
- 学科特定表达规范
- 术语表创建和维护

## 翻译原则

### 1. 准确性原则
- 专业术语翻译准确
- 数值和单位精确
- 逻辑关系清晰

### 2. 学术规范
- 符合学术写作规范
- 使用被动语态（英文）
- 避免口语化表达

### 3. 地道表达
- 英文：符合英语学术表达习惯
- 中文：符合中文学术写作规范

## 常用学术表达对照

### 英文常用表达
| 中文 | 英文 |
|------|------|
| 本文提出 | This paper proposes/presents |
| 实验结果表明 | Experimental results demonstrate/show |
| 与...相比 | Compared with... |
| 显著提高 | Significantly improve/enhance |
| 研究表明 | Studies indicate/reveal |
| 综上所述 | In summary/conclusion |

### 中文常用表达
| 英文 | 中文 |
|------|------|
| This study aims to | 本研究旨在 |
| The results suggest that | 结果表明 |
| In contrast | 相比之下 |
| Furthermore | 此外 |
| It is worth noting that | 值得注意的是 |

## 翻译流程

1. **预处理**
   - 识别专业术语
   - 确定学科领域
   - 了解目标读者

2. **翻译**
   - 逐段翻译
   - 保持术语一致
   - 注意句子衔接

3. **后处理**
   - 检查语法错误
   - 核对专业术语
   - 润色表达

## 特殊处理

### 公式和符号
- 保持原样，不翻译
- 注意符号说明的翻译

### 图表标题
- 翻译图表标题和说明
- 保持图注完整

### 参考文献
- 保持原文格式
- 仅翻译引用说明

## 适用场景

- 投稿国际期刊
- 学位论文英文摘要
- 学术交流邮件
- 国际会议论文
