# 论文阅读助手 (Paper Reader)

专门帮助硕博研究生快速阅读和理解学术论文的技能。

## 主要功能

### 1. 论文摘要提取
- 自动提取论文标题、作者、发表信息
- 生成结构化摘要（背景、目的、方法、结果、结论）
- 识别论文的研究问题和假设

### 2. 核心贡献分析
- 识别论文的主要创新点
- 分析理论贡献和实践意义
- 评估研究的学术价值

### 3. 方法论解读
- 解析研究方法和实验设计
- 解释技术细节和算法原理
- 分析数据收集和处理方式

### 4. 结果与讨论
- 总结实验结果和发现
- 分析结论的可靠性
- 识别研究的局限性

## 使用方式

当用户提供论文内容或论文文件时，可以：

1. **快速概览**：生成论文的简要总结
2. **深度分析**：详细解读论文的各个部分
3. **对比阅读**：比较多篇论文的异同
4. **问题解答**：回答关于论文的具体问题

## 输出格式

```
## 论文基本信息
- 标题：
- 作者：
- 发表年份/期刊：

## 研究背景与问题
[背景描述]

## 核心贡献
1. [贡献1]
2. [贡献2]

## 方法论
[方法描述]

## 实验结果
[结果总结]

## 研究局限
[局限性分析]

## 个人笔记
[可记录自己的想法和疑问]
```

## 适用场景

- 快速筛选相关文献
- 准备组会汇报
- 撰写文献综述
- 寻找研究灵感
