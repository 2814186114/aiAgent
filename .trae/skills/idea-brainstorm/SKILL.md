# 研究创意助手 (Idea Brainstorm)

帮助硕博研究生激发研究灵感和挖掘创新点的技能。

## 主要功能

### 1. 创意激发
- 研究方向探索
- 创新点挖掘
- 问题发现

### 2. 思维拓展
- 跨学科思维
- 逆向思维
- 组合创新

### 3. 可行性评估
- 创新性评估
- 可行性分析
- 价值判断

### 4. 方案细化
- 想法具体化
- 研究设计
- 实施路径

## 创新思维方法

### 1. 问题驱动法
```
步骤：
1. 列出领域痛点
2. 分析问题本质
3. 寻找解决思路
4. 验证可行性

示例：
痛点：现有方法计算效率低
本质：算法复杂度高
思路：引入近似算法/并行计算
验证：理论分析+初步实验
```

### 2. 方法迁移法
```
步骤：
1. 发现其他领域的优秀方法
2. 分析方法的核心思想
3. 思考在本领域的适用性
4. 进行适应性改造

示例：
来源：计算机视觉中的注意力机制
核心：动态权重分配
迁移：应用于自然语言处理
改造：设计适合文本的注意力结构
```

### 3. 组合创新法
```
步骤：
1. 识别多个相关技术
2. 分析各自优势
3. 设计组合方式
4. 验证协同效果

示例：
技术A：深度学习特征提取
技术B：传统机器学习分类器
组合：深度特征+传统分类器
优势：兼顾特征表达和可解释性
```

### 4. 逆向思维法
```
步骤：
1. 明确常规思路
2. 反向思考
3. 发现新视角
4. 验证价值

示例：
常规：提高模型复杂度提升性能
逆向：简化模型保持性能
发现：轻量化模型研究
```

## 创意评估矩阵

### 评估维度
| 维度 | 评估问题 | 权重 |
|------|----------|------|
| 创新性 | 是否有足够新意？ | 30% |
| 可行性 | 技术上能否实现？ | 25% |
| 价值性 | 理论/实践意义？ | 25% |
| 适切性 | 是否适合自己？ | 20% |

### 评分标准
| 分数 | 标准 |
|------|------|
| 5 | 非常好，强烈推荐 |
| 4 | 较好，值得尝试 |
| 3 | 一般，可以考虑 |
| 2 | 较差，不太推荐 |
| 1 | 很差，不建议 |

### 决策矩阵
```markdown
# 创意评估表

| 创意 | 创新性 | 可行性 | 价值性 | 适切性 | 总分 |
|------|--------|--------|--------|--------|------|
| 创意A | 4 | 5 | 4 | 4 | 4.25 |
| 创意B | 5 | 3 | 4 | 3 | 3.85 |
| 创意C | 3 | 5 | 3 | 5 | 3.80 |

结论：优先选择创意A
```
