# 幻灯片制作助手 (Slide Maker)

帮助硕博研究生制作专业学术演示PPT的技能。

## 主要功能

### 1. 内容规划
- 演示结构设计
- 内容层次安排
- 时间分配建议

### 2. 大纲生成
- 自动生成PPT大纲
- 各页内容建议
- 关键要点提炼

### 3. 设计建议
- 配色方案推荐
- 布局设计建议
- 图表使用指导

### 4. 演示技巧
- 演讲节奏把控
- 互动环节设计
- Q&A准备

## PPT大纲模板

### 论文汇报大纲
```markdown
# [论文标题]

## 第1页：封面
- 论文标题
- 作者及单位
- 汇报人信息
- 日期

## 第2页：目录
- 研究背景
- 研究方法
- 实验结果
- 结论与展望

## 第3-4页：研究背景
- 领域现状
- 存在问题
- 研究动机

## 第5页：研究问题
- 核心问题
- 研究假设

## 第6-7页：研究方法
- 方法框架图
- 关键技术说明

## 第8-10页：实验结果
- 实验设置
- 对比实验
- 消融实验

## 第11页：结论
- 主要发现
- 研究贡献

## 第12页：未来工作
- 研究局限
- 改进方向

## 第13页：致谢
- 感谢导师和团队
- Q&A
```

## 设计原则

### 1. 简洁原则
- 每页一个核心观点
- 文字不超过6行
- 使用关键词而非完整句子

### 2. 视觉层次
- 标题醒目
- 重点内容突出
- 逻辑关系清晰

### 3. 一致性
- 统一字体和配色
- 统一图表风格
- 统一动画效果

### 4. 专业性
- 数据准确
- 图表规范
- 引用完整

## 配色方案推荐

| 主色 | 辅色 | 强调色 | 适用场景 |
|------|------|--------|----------|
| 深蓝 | 浅灰 | 橙色 | 理工科 |
| 深绿 | 米白 | 金色 | 环境类 |
| 酒红 | 浅灰 | 金色 | 人文社科 |
| 深灰 | 白色 | 蓝色 | 通用 |

## 图表使用建议

### 何时使用图表
| 内容类型 | 推荐形式 |
|----------|----------|
| 流程/框架 | 流程图 |
| 数据对比 | 柱状图/表格 |
| 趋势变化 | 折线图 |
| 比例关系 | 饼图（少用） |
| 结构关系 | 结构图 |

### 图表规范
- 标题清晰
- 坐标轴标签完整
- 图例位置合理
- 数据来源标注

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 文字过多 | 提取关键词，详情口述 |
| 图表模糊 | 使用矢量图，提高分辨率 |
| 逻辑不清 | 使用过渡页，明确章节 |
| 时间超时 | 每页控制在1-2分钟 |

## 适用场景

- 论文汇报
- 开题报告
- 毕业答辩
- 学术会议
